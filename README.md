# المساعد المحاسبي الصوتي الذكي — النقابة العامة للبناء والاخشاب

تطبيق وكلاء ذكاء اصطناعي صوتي (Gemini Live API) يتحدث العربية، ويسجّل القيود المحاسبية
المزدوجة، ويستعلم عن الأرصدة وميزان المراجعة بالجنيه المصري (ج.م) — مع واجهة محاسبية
كاملة تعمل أوفلاين (IndexedDB) وتُزامن القيود عند عودة الإنترنت.

---

## 1) المتطلبات

| المتطلب | التفاصيل |
| --- | --- |
| Node.js | الإصدار 18 أو أحدث (مُجرَّب على 22) |
| مفتاح Gemini API | مجاني من [Google AI Studio](https://aistudio.google.com/apikey) |
| متصفح | Chrome / Edge / Safari حديث (للميكروفون والصوت) |

---

## 2) التشغيل السريع (3 خطوات)

```bash
# 1) تثبيت الحزم
npm install

# 2) (اختياري) ضع المفتاح في ملف البيئة
cp .env.example .env
#   ثم افتح .env وضع مفتاحك بعد GEMINI_API_KEY=
#   أو تجاهل هذه الخطوة وأدخل المفتاح من داخل الواجهة.

# 3) تشغيل التطبيق
npm run dev
```

ثم افتح المتصفح على: **http://localhost:3000**

### إدخال مفتاح API من الواجهة (بدون ملف .env)

عند أول تشغيل تظهر نافذة **«مفتاح Gemini API لتشغيل الوكلاء الصوتيين»**:

1. اضغط رابط Google AI Studio ثم **Create API key** وانسخ المفتاح (يبدأ بـ `AIza`).
2. الصقه في الحقل واضغط **«حفظ وتشغيل»**.
3. يبدأ الاتصال الصوتي تلقائياً.

المفتاح يُحفظ في `localStorage` داخل متصفحك فقط، ولا يُرسل إلى أي سيرفر وسيط.
يمكن تغييره أو حذفه في أي وقت من زر **«المفتاح جاهز»** في الشريط العلوي.

---

## 3) طريقة الاستخدام

1. اضغط **«اتصال صوتي»** (أو الدائرة المضيئة) واسمح للمتصفح باستخدام **الميكروفون**.
2. تحدث بالعربية مباشرة، مثل:
   - «كم رصيد الخزينة وحساب البنك الأهلي حالياً؟»
   - «أعطني الملخص المالي والفائض للنقابة»
   - «سجل قيد تحصيل اشتراكات نقداً بـ 15,000 جنيه»
   - «ما هو رصيد صندوق الرعاية ببنك مصر؟»
   - «هل ميزان المراجعة متزن بدقة؟»
3. يمكنك أيضاً الكتابة في مربع النص أسفل الشاشة، أو النقر على **الأوامر الصوتية السريعة**.
4. كل استدعاء أداة (Function Calling) يظهر في «سجل الحوار والأوامر الصوتية» مع نتيجة التنفيذ.

> إذا لم يعمل الميكروفون (مثلاً داخل iframe مقيّد أو صلاحية مرفوضة) فاستخدم مربع النص — كل
> أدوات المحاسبة تعمل بالكامل.

## 4) الوكلاء (الشخصيات) المتاحون

| الوكيل | الدور | الصوت |
| --- | --- | --- |
| أحمد — المستشار المالي للنقابة | المستشار المالي ومدير الحسابات | Kore |
| سارة — مدققة الحسابات النقابية | رئيسة التدقيق المالي الداخلي | Aoede |
| عمر — مستشار صندوق الزمالة والضرائب | الميزانية وصناديق الرعاية | Charon |

اختر الوكيل من قائمة **«الشخصية»** في الشريط العلوي.

### الأدوات المحاسبية التي يستدعيها الوكيل تلقائياً

| الأداة | الوظيفة |
| --- | --- |
| `get_account_balance` | رصيد أي حساب بالاسم أو الكود |
| `get_financial_summary` | الأصول، الالتزامات، الإيرادات، المصروفات، الفائض، توازن الميزان |
| `create_journal_entry` | تسجيل قيد مزدوج (يرفض أي قيد غير متزن) |
| `list_recent_journal_entries` | آخر القيود المسجلة |
| `search_transactions` | البحث بالوصف أو نطاق المبالغ |
| `get_party_balance` | رصيد لجنة فرعية / مستشفى / مورد |

## 5) أوامر الأوامر السكربتية

```bash
npm run dev        # تشغيل بيئة التطوير على http://localhost:3000
npm run build      # إنتاج نسخة للنشر داخل مجلد dist
npm run preview    # معاينة نسخة الإنتاج
npm run lint       # فحص أنواع TypeScript (tsc --noEmit)
```

للنشر: نفّذ `npm run build` ثم ارفع محتوى مجلد `dist` على أي استضافة ثابتة
(Vercel / Netlify / GitHub Pages) — مع مراعاة أن المتصفح يحتاج HTTPS لاستخدام الميكروفون.

## 6) حل المشكلات

| المشكلة | الحل |
| --- | --- |
| «مفتاح Gemini API غير صالح أو غير مصرّح» | أعد إدخال المفتاح من زر «المفتاح» وتأكد من نسخه كاملاً (يبدأ بـ `AIza`) |
| «تم استهلاك الحصة المجانية اليومية» | حصة Gemini Live المجانية محدودة يومياً — استخدم مفتاحاً آخر أو أعد المحاولة غداً |
| الميكروفون لا يعمل | اسمح بإذن الميكروفون في المتصفح، واستخدم `localhost` أو HTTPS، أو استعمل مربع النص |
| لا صوت للوكيل | تأكد أن تبويب المتصفح غير مكتوم وأن مستوى الصوت مفتوح (الصوت يُولَّد عند إرسال أول رسالة/نقرة) |
| الشاشة الحمراء «ميزان المراجعة غير متزن» | اضغط «تصفير البيانات التجريبية» من تبويب المزامنة لإعادة تحميل البيانات النموذجية المتوازنة |
| المتصفح يحجب الاتصال بالنطاق | تم ضبط `server.allowedHosts` في `vite.config.ts` ليقبل نطاقات المعاينة المُوجّهة |

```
components/voice/VoiceConsole  وحدة التحكم الصوتي والتفريغ النصي
components/accounting/*        التقارير، دفتر اليومية، دليل الحسابات، المزامنة
```
